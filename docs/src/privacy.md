# プライバシー

[English](en/privacy.html)

Time Wise は、利用時間の把握に必要な最小限の情報を扱います。

## 記録する情報

- フォーカスされているアプリの識別情報と表示名
- アプリがフォーカスされていた時間
- 表示に使用するアプリアイコン

## 記録しない情報

- ウィンドウタイトル
- 文書名やメール件名
- 閲覧 URL、Web サイト、ブラウザータブ
- バックグラウンドで起動しているだけの時間
- 画面ロック中やスリープ中の時間

利用履歴は OS ユーザーごとの端末内領域に保存され、現在のバージョンではサーバーへ送信されません。履歴は設定画面から削除できます。
